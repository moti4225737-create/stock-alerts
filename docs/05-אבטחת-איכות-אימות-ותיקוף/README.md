# 05 — אבטחת איכות, אימות ותיקוף

ענף זה מגדיר כיצד מוכיחים שמימוש Stock Sentinel ושינויים בו נכונים, יציבים ותואמים את הדרישות.

## שני תחומים מרכזיים

### אימות הנדסי ומערכתי

בודק האם המימוש מקיים את החוזים וההתנהגות שנדרשו ממנו ואינו שובר התנהגות קיימת.

כולל בין היתר:

- בדיקות המגדירות חוזה.
- בדיקות ממוקדות.
- Full Regression.
- בדיקות דטרמיניסטיות לאינטגרציות.
- Quality Gates / Quality Controls.
- בקרת שינויים הנדסיים.

### תיקוף מוצרי

בודק האם היכולת שנבנתה אכן משיגה את הערך והמטרה שלשמם נבנתה בעולם האמיתי.
