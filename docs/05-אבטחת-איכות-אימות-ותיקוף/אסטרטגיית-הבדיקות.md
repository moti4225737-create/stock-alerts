# אסטרטגיית הבדיקות

מטרת הבדיקות היא להוכיח שהמימוש מקיים את החוזים וההתנהגות שנדרשו ממנו.

## עקרונות

- Tests define the contract.
- בדיקה צריכה להיות דטרמיניסטית ככל שניתן.
- בדיקות חיצוניות אינן אמורות להיות תלויות בשינוי מקרי של שירות בזמן הריצה.
- כל שינוי מתחיל בבדיקה ממוקדת כאשר הדבר מתאים.
- לאחר מעבר הבדיקה הממוקדת מבוצע Full Regression.

## שכבות בדיקה

בהתאם לצורך ניתן להשתמש ב:

- Unit Tests;
- Integration Tests;
- Contract Tests;
- System Tests;
- Benchmark / Evaluation Cases.

הבחירה בסוג הבדיקה נגזרת מהסיכון ומהחוזה שיש להוכיח.

## אינטגרציות חיצוניות

בדיקות אינטגרציה צריכות להפריד ככל שניתן בין:

- בדיקת הלוגיקה שלנו;
- בדיקת החוזה מול Provider;
- תלות זמנית וזמינות של שירות חיצוני.

המטרה היא למנוע מצב שבו בדיקה הופכת לאדומה רק משום שהעולם החיצוני השתנה ברגע ההרצה.
