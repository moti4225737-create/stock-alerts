# Validation ו־Benchmarks

Testing ו־Validation אינם אותו דבר.

Testing שואל:
"האם המימוש מקיים את החוזה?"

Validation שואל:
"האם היכולת שבנינו באמת משיגה את המטרה שלשמה נבנתה?"

## Product Validation

Stock Sentinel צריך להיבחן גם מול שימוש אמיתי ולא רק מול בדיקות אוטומטיות.

מדדים אפשריים ל־Alpha כוללים:

- Recall;
- Latency;
- Precision;
- Grounding;
- Correlation;
- Personal Relevance;
- Human Effort;
- Decision Usefulness;
- Time-to-Awareness.

## Competitive Substitution

האלטרנטיבה האמיתית אינה רק מוצר מתחרה יחיד.

יש להשוות גם מול:

Existing Tools
+ Manual Workflow
+ General AI.

אם המשתמש יכול להשיג כמעט את אותו ערך בקלות ובעלות נמוכה יותר, Stock Sentinel עדיין לא הוכיח יתרון מוצרי מספיק.

## Benchmark Cases

Benchmark טוב צריך לבדוק לא רק הצלחות אלא גם:

- misses;
- false positives;
- wrong correlations;
- unsupported conclusions;
- misleading confidence;
- late detection.

הצלחה אנקדוטלית אחת אינה מספיקה להוכחת המוצר.
