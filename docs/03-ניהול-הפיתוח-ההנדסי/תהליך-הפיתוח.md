# תהליך הפיתוח המבוקר

מטרת תהליך הפיתוח היא לאפשר ל־Stock Sentinel להתקדם במהירות הנכונה בלי לאבד נכונות, יציבות, עקיבות או שליטה בהחלטות.

## עקרונות

- עובדים לפי TDD: RED → GREEN → REFACTOR.
- מתחילים מהשינוי הקטן והנכון ביותר שמקיים את החוזה.
- נמנעים ממורכבות שאינה נדרשת.
- אין הרחבת Scope שקטה.
- שינוי משמעותי מוסבר ונבחן לפני מימוש.
- כאשר קיים מבנה מתאים, מרחיבים אותו לפני יצירת מסלול מקביל.
- פתרון ברור עדיף על פתרון מתוחכם שקשה להבין ולתחזק.
- קוד זמני אינו נשאר במימוש Production.

## AI ושיקול דעת הנדסי

כלי AI ואוטומציה נועדו לחזק את שיקול הדעת ההנדסי ולא להחליף אותו.

אוטומציה יכולה לצמצם עבודה חוזרת; היא אינה מחליפה חשיבה קריטית, בדיקת השפעה, ביקורת או החלטה אנושית בנקודות המחייבות זאת.

אישור שניתן לעבודה קודמת אינו נחשב אישור אוטומטי לפעולה חדשה.
