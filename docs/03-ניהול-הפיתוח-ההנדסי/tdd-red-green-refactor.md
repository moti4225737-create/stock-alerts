# TDD — RED → GREEN → REFACTOR

TDD הוא מנגנון הפיתוח הבסיסי של Stock Sentinel.

## RED

מגדירים תחילה את ההתנהגות או החוזה באמצעות בדיקה שנכשלת מהסיבה הצפויה.

אין מתחילים מימוש לפני שה־RED הובן ואושר במסגרת העבודה הרלוונטית.

## GREEN

מממשים את הפתרון הקטן והנכון ביותר שגורם לבדיקה לעבור.

אין מוסיפים יכולות, abstractions או refactoring שאינם נדרשים לחוזה הנוכחי.

## REFACTOR

לאחר שהחוזה מתקיים והבדיקות ירוקות, משפרים מבנה רק כאשר יש לכך הצדקה אמיתית ותוך שמירת ההתנהגות.

## אימות

לאחר שינוי:
- מריצים בדיקות ממוקדות.
- מריצים Full Regression.
- בוחנים את ה־diff ואת מצב המאגר.
- ממשיכים ל־Commit רק לאחר שהשינוי עבר את שערי האיכות והבקרה.
