# 02 — ספר המוצר

ענף זה מתאר את Stock Sentinel כמוצר: מהו, למה הוא קיים, מה נדרש ממנו, כיצד הוא בנוי ולאן הוא מתפתח.

## תוכן

### 02.01 — חזון המוצר
מתאר את תמונת היעד והערך ארוך הטווח של Stock Sentinel.

### 02.02 — הגדרת המוצר
מגדיר מהו Stock Sentinel ומה הוא אינו.

### 02.03 — דרישות המוצר
מרכז את הדרישות שהמוצר חייב לקיים.

### 02.04 — כיוון והתפתחות המוצר
מתעד את כיוון ההתפתחות המאושר של המוצר בלי להפוך רעיונות עתידיים לדרישות מימוש מיידיות.

### 02.05 — ארכיטקטורת המערכת
מתאר את המבנה המקצועי של המערכת, גבולותיה, רכיביה, הזרימות והנושאים הרוחביים שלה.
