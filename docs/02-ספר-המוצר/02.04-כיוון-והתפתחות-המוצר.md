# 02.04 — כיוון והתפתחות המוצר

Stock Sentinel מתפתח בשלבים. יציבות של שלב אינה סוף הדרך אלא בסיס לשלב הבשלות הבא.

## מסלול המוצר המאושר

1. להשלים ולייצב Alpha מלוטשת ונכונה למשתמש יחיד.
2. להוכיח פעולה רציפה עם מקורות המידע המאושרים.
3. להשלים Source-Grounded Summary ותוצר משתמש איכותי.
4. למדוד ערך בפעילות אמיתית ולא רק הצלחת בדיקות.
5. לבצע Architecture Review v1.0 לאחר גרסת משתמש יציבה ונכונה.
6. לפתוח יכולות Scale או Commercialization כאשר Triggers אמיתיים מצדיקים אותן.

## עיקרון Evolution Gate

יכולת שמספקת את הצורך הנוכחי אך דורשת שדרוג עתידי אינה נחשבת נשכחת.

היא נרשמת ב־Evolution Register עם מצב נוכחי, מצב יעד, Trigger, Milestone וקריטריוני Validation.

## כיוונים עתידיים

אפשרויות כגון:
- Multi-user;
- Multi-portfolio;
- Professional / institutional workflows;
- Broker integrations;
- Voice interaction;
- Embedded intelligence;
- APIs;

נשמרות כאפשרויות התפתחות ולא כ־Scope של ה־Alpha, אלא אם החלטת מוצר עתידית משנה זאת.

אין לבנות מורכבות מוקדמת רק משום שיכולת עשויה להיות רצויה בעתיד.
