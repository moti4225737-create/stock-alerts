# 02.05.04 — סביבת הפעלה ופריסה

Stock Sentinel מפותח במאגר Git מבוקר ומיועד לפעול בסביבת Production רציפה.

## סביבת הפיתוח הנוכחית

- Python.
- Git / GitHub.
- בדיקות אוטומטיות באמצעות pytest.
- Configuration ו־Secrets מחוץ לקוד.
- אינטגרציות חיצוניות דרך Providers / Clients ייעודיים.

## Production

סביבת Production צריכה:
- להפעיל את תהליכי האיסוף והתזמון;
- לשמור state נדרש;
- לאפשר delivery לערוצים המאושרים;
- להפריד Secrets מהקוד;
- לאפשר ניטור והתאוששות.

## Least Privilege

גישה של שירותי Deployment ו־CI/CD למאגר ולסביבות צריכה להיות מוגבלת לנדרש.

## Reliability Boundary

Scheduler פנימי אינו יכול לבדו להוכיח שהוא עצמו עדיין חי.

לכן Production Reliability כוללת External Production Lifeguard בלתי תלוי במסלול הכשל של Sentinel.

במימוש הנוכחי, השלמה מוצלחת של עבודת מקור אוטונומית מייצרת Work Evidence למנטר חיצוני.

היעדר Work Evidence צפוי מאפשר זיהוי DOWN מחוץ למערכת, וחזרת Work Evidence מאפשרת זיהוי Recovery / UP.

הפרטים התפעוליים, ה־runtime wiring וה־Validation מתועדים בענף התפעול בבית הסמכותי של Production Reliability.
