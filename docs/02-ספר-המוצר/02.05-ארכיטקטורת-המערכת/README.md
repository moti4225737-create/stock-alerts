# 02.05 — ארכיטקטורת המערכת

ענף זה מתאר כיצד Stock Sentinel בנוי כדי לקיים את מטרות המוצר.

הוא עוסק במבנה, אחריות, גבולות, תלויות, חוזים, זרימות ויחסים בין חלקי המערכת — ולא בשיטת העבודה של צוות הפיתוח.

## תוכן

### 02.05.01 — הקשר וגבולות המערכת
מגדיר את סביבת Stock Sentinel, מה נמצא בתוך המערכת ומה מחוצה לה, ואת הגבולות מול מערכות ושירותים חיצוניים.

### 02.05.02 — מבנה ורכיבי המערכת
מתאר את הרכיבים המרכזיים, שכבות המערכת ותחומי האחריות שלהם.

### 02.05.03 — תהליכים ואינטראקציות
מתאר את זרימות המידע והאינטראקציות בין רכיבים לאורך תהליכי המודיעין וה־runtime.

### 02.05.04 — סביבת הפעלה ופריסה
מתאר את סביבת הריצה, התלויות התפעוליות והמבנה הנדרש לפריסה.

### 02.05.05 — נושאים רוחביים
מרכז עקרונות ארכיטקטוניים החוצים מספר רכיבים או שכבות, כגון גבולות ותלויות, אבטחה, חוסן והתפתחות עתידית.
