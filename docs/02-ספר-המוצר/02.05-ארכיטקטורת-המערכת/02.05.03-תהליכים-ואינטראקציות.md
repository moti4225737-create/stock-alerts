# 02.05.03 — תהליכים ואינטראקציות

שרשרת המודיעין העקרונית של Stock Sentinel היא:

Collect
→ Normalize
→ Correlate
→ Interpret
→ Explain
→ Evaluate Portfolio Impact
→ Present
→ Deliver.

## Source-Grounded Understanding

כאשר קיים מקור סמכותי:

1. המקור המלא נקרא ככל שהפורמט מאפשר.
2. מזוהים Facts / Developments מועמדים.
3. טענות עובדתיות נקשרות לראיות במקור.
4. הממצאים מדורגים לפי מהותיות למשקיע.
5. נוצרת תמצית עובדתית קצרה.
6. רק לאחר מכן מתווספים Interpretation ו־Portfolio Impact.

המטרה היא למנוע מצב שבו ניסוח משכנע קודם לביסוס העובדות.

## Correlation

אירועים ממקורות שונים יכולים להתאחד ל־Intelligence Story כאשר הם מתארים אותה התפתחות.

מקורות משניים יכולים להעשיר את ההקשר, אך חזרה מרובה על אותה טענה אינה הופכת אותה לעובדה.

## Presentation Flow

התוצר המוצג מפריד ככל שנדרש בין:
- מה קרה;
- הראיות והמקור;
- משמעות האירוע;
- ההשפעה האפשרית;
- הקשר לתיק;
- מה ראוי לבדיקה.

הצגה אינה אמורה להסתיר אי־ודאות שקיימת בשכבות הקודמות.
