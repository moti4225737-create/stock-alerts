# 02.05.05 — נושאים רוחביים במערכת

ענף זה מרכז עקרונות ויכולות ארכיטקטוניים שאינם שייכים לרכיב יחיד אלא חוצים מספר שכבות של Stock Sentinel.

בין הנושאים שנמפו לכאן:
- גבולות ותלויות במערכת.
- תכנון להתפתחות עתידית.
- שלמות מודל המוצר.
- אבטחת המערכת.
- אמינות וחוסן מערכתיים.

עומק נוסף ייווצר רק כאשר מספר פרטים מאותה מהות יצדיקו כלל וענף עצמאי.

## עקרונות תכנון ארכיטקטוניים

Stock Sentinel מונחה על ידי:

- Clean Architecture — הפרדת אחריויות ותלויות כך שליבת המוצר אינה נשלטת על ידי פרטי תשתית או ספקים חיצוניים.
- SOLID — עקרונות תכנון המסייעים לשמור על אחריות ברורה, הרחבה מבוקרת ותלויות ניתנות להחלפה.
- Domain-Driven Design — מודל המוצר מבוסס על מושגים מפורשים של הדומיין ולא על מבנה מקרי של API, Provider או Payload חיצוני.

עקרונות אלה הם גישות תכנון ולא חוקה. ניתן להתאים את דרך מימושם עם התפתחות המוצר כל עוד נשמרת המטרה הארכיטקטונית שהם משרתים.
