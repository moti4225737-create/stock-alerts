# תכנון פתוח לגרסאות עתידיות

Stock Sentinel נבנה תחילה למשתמש יחיד, אך אין ליצור מגבלות ארכיטקטוניות מיותרות שיחייבו בנייה מחדש כאשר המוצר יבשיל.

## עיקרון

Preserve options without pre-building hypothetical scale.

המערכת צריכה לשמור אפשרות סבירה להתפתחות לכיוונים כגון:
- multi-user;
- multi-portfolio;
- multi-channel;
- replaceable providers;
- professional workflows;
- embedded intelligence.

עם זאת, אין להוסיף כיום services, abstractions, distributed infrastructure או שכבות מורכבות שאין להן צורך ממשי בשלב הנוכחי.

## Trigger

כאשר צורך מסחרי, תפעולי או מוצרי אמיתי מצדיק Scale, נפתח תכנון מפורש לשלב הבא דרך Evolution Gate ולא באמצעות מורכבות שקטה בתוך ספרינט אחר.
