# 01 — יסודות המוצר

ענף זה שומר את הזהות, התכלית והעקרונות היציבים של Stock Sentinel.

הוא מכיל רק עקרונות שאינם אמורים להשתנות בגלל החלפת טכנולוגיה, כלי פיתוח, צוות, ספק או שיטת מימוש.

## תוכן
