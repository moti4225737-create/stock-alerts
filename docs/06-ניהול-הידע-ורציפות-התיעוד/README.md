# 06 — ניהול הידע ורציפות התיעוד

ענף זה מנהל את ה־Controlled Source of Truth של Stock Sentinel ואת רציפות הידע לאורך חיי המוצר.

הוא אינו "הארכיון כולו".

01–06 יחד מהווים את ארכיון המוצר; ענף 06 מגדיר כיצד הארכיון עצמו מנוהל, מתעדכן ונשמר.

## תחומי אחריות

- מבנה הארכיון וכללי התיעוד.
- Current Truth.
- Documentation Inventory.
- Documentation Checkpoints.
- Version Alignment.
- Chronicle והיסטוריית ספרינטים.
- Traceability.
- שימור ורציפות ידע.
- ניהול גישה, הרשאות וחשיפת מידע.

## עיקרון יסוד

R&D מכתיב את מצב המוצר בפועל.

הארכיון מתעד ומקבע את המצב המאומת ואינו מכתיב שינוי למוצר רק כדי להתאים למסמך.

לכל מידע סמכותי יש Natural Home אחד.

## קשר לפרוטוקול הסמכותי

ה־Closure Authority היחיד של שינוי End-to-End נמצא ב־:

`../03-ניהול-הפיתוח-ההנדסי/פרוטוקול-השינוי-האימות-המסירה-והסגירה-הסמכותי.md`

Documentation Checkpoint הוא בקרה פנימית מחייבת של אותו פרוטוקול.

הוא אינו Gate עליון נפרד.

## סיום ספרינט או שלב

במסגרת Documentation Checkpoint נשמרים לפחות:

1. Current Truth — מה נכון במוצר עכשיו.
2. Chronicle — מתי, למה וכיצד השתנה.
3. Traceability — קישור למסמכים, החלטות, בדיקות, Commit / Tag / Version והראיות הרלוונטיות.

Closure של הספרינט או השלב נקבע רק לאחר שכל דרישות הפרוטוקול הסמכותי הרלוונטיות עברו.
