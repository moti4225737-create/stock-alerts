# 07 — פרסום ומידע ציבורי

מידע הופך לציבורי רק בעקבות החלטת פרסום מפורשת.

## Public Release Gate

לפני פרסום בודקים:

- האם החומר חושף IP;
- האם הוא חושף Security Details;
- האם קיימים Secrets או Identifiers;
- האם קיימת מגבלה משפטית, חוזית או רגולטורית;
- האם צירוף החומר לפרסומים קיימים יוצר Aggregation Risk;
- האם רמת הפירוט באמת נדרשת למטרת הפרסום.

## עיקרון

Public Documentation צריך להסביר את הנדרש לציבור בלי להפוך למפת שחזור של המערכת הפנימית.
