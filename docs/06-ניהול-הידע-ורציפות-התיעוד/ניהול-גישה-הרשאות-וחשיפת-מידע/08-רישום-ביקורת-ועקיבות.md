# 08 — רישום, ביקורת ועקיבות

הקצאות ושינויים רגישים בהרשאות צריכים להיות ניתנים לעקיבה בהתאם לרמת הסיכון.

כאשר רלוונטי נשמרים:

- מבקש;
- מאשר;
- מבצע טכני;
- Scope;
- Purpose;
- תוקף;
- מה נחשף;
- מועד שינוי או שלילה.

## Disclosure Record

בחשיפה חיצונית משמעותית יש לשמור תיעוד של:

מה נמסר
→ למי
→ למה
→ מי אישר
→ באילו תנאים
→ ולכמה זמן.

המטרה היא Accountability, חקירת אירוע והגנת IP — לא בירוקרטיה לשמה.
