# 05 — הגנת IP וחשיפה מבוקרת

Stock Sentinel עשוי להכיל IP שמקורו בשילוב ארכיטקטורה, לוגיקה, תהליכים, ידע והחלטות מצטברות.

הגנת IP אינה נמדדת רק לפי קובץ בודד.

## Aggregation Risk

מספר פריטי מידע שכל אחד מהם בטוח בפני עצמו עלולים יחד לחשוף את המערכת ברמת שחזור.

לכן נבדקת גם החשיפה המצטברת.

## Reconstructability Risk

לפני חשיפה עמוקה נשאל:

האם המידע שכבר נמסר + המידע החדש + היכולת הקיימת של הצד המקבל יוצרים יכולת מעשית לשחזר חלק מהותי מהמוצר?

## עיקרון

Proof of Capability אינו מחייב Full Implementation Disclosure.

החשיפה עולה רק כאשר אין חלופה מספקת ומטרת התהליך מצדיקה את הסיכון.
