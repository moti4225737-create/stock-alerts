# 06 — משקיע או שותף פוטנציאלי

משקיע או שותף פוטנציאלי אינו מקבל הרשאה קבועה.

החשיפה נגזרת מ־Disclosure Lifecycle.

## מסלול

1. פנייה ראשונית — בעיה, חזון, Value Proposition ויכולות ברמת־על.
2. עניין ראשוני — Demo מבוקר ומידע עסקי נוסף.
3. Confidentiality Gate — פתיחת חומר פנימי מוגדר לאחר מסגרת מתאימה.
4. Qualified Interest — Product Maturity, Roadmap, Validation וארכיטקטורה ברמת־על.
5. Term Sheet או מחויבות ממשית — Due-Diligence Package רחב יותר לפי צורך.
6. Due Diligence — Data Room מדורג לפי תחומים.
7. Protected IP Review — רק כאשר הכרחי ובמנגנון חשיפה מבוקר.

## עיקרון

התקדמות עסקית אינה מעניקה אוטומטית התקדמות בחשיפת IP.

כל מדרגת חשיפה דורשת הצדקה ואישור נפרדים.

שותף פוטנציאלי נשאר במודל זה עד ששותפות רשמית מגדירה Role חדש. שותפות אינה מקנה אוטומטית הרשאות Owner.
