# 02 — הארכיטקט הראשי

הארכיטקט הראשי זקוק לראייה מערכתית רחבה כדי לתכנן, לבקר ולהוביל את התפתחות Stock Sentinel.

## הרשאת בסיס

- גישה רחבה לחוקה, מוצר, ארכיטקטורה, R&D, QA ו־Chronicle.
- גישה לקוד ול־IP הטכני לפי צורך העבודה.
- יכולת להציע וליישם שינוי מאושר במסגרת הכלים וההרשאות שהוקצו.

## מגבלות

- אין סמכות עצמאית לשנות חוקה, מבנה ארכיון או החלטות יסוד.
- אין סמכות להעניק או להרחיב הרשאות.
- Secrets חיים הם Default Deny.
- Production הוא Default Deny ונפתח נקודתית רק כאשר המשימה מחייבת ובאישור.
- אין העברת IP לצד שלישי ללא אישור מפורש.

## תוקף

הרשאת הבסיס קיימת מכוח התפקיד.

הרשאות רגישות חריגות הן נקודתיות, מוגבלות למשימה ובעלות תוקף מוגדר.
