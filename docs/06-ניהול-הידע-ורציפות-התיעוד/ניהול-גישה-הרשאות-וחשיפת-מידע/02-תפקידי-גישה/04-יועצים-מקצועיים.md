# 04 — יועצים מקצועיים

יועץ מקצועי מקבל רק את המידע הנדרש למשימה ולתחום מומחיותו.

דוגמאות כוללות עורך דין, יועץ קניין רוחני, רואה חשבון, יועץ אבטחה או יועץ רגולטורי.

## ברירת מחדל

- מידע מוצרי — לפי צורך.
- ארכיטקטורה ו־IP — רק כאשר נדרשים מקצועית ובאישור.
- Source Code — Default Deny.
- Production — אין גישה.
- Secrets / Credentials — אין גישה.
- שינוי מסמכי מקור — לא כברירת מחדל.

## חבילת חשיפה

ככל שניתן, היועץ מקבל Disclosure Package ממוקד ולא גישה כללית לארכיון.

## Confidentiality Gate

חומר IP או מידע עסקי רגיש נחשפים רק לאחר שהמעטפת המשפטית המתאימה קיימת, כאשר היא נדרשת.

## תוקף

גישה חיצונית מקבלת כברירת מחדל מועד בחינה או תפוגה ונשללת או מחודשת במפורש בסיום הצורך.
