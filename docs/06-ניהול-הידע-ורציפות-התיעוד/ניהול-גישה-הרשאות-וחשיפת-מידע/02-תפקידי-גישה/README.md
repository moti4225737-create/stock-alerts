# 02 — תפקידי גישה

ההרשאה נגזרת מהתפקיד, מהמטרה, מהשלב בתהליך ומהסיכון — לא מהמעמד בלבד.

## התפקידים המאושרים

1. בעל המוצר.
2. הארכיטקט הראשי.
3. הצוות הטכני.
4. יועצים מקצועיים.
5. מבקר חיצוני.
6. משקיע או שותף פוטנציאלי.
7. רוכש פוטנציאלי.
8. שירותים ומערכות אוטומטיות.
9. ציבור או גורם חיצוני לא מורשה.

כל תפקיד מתאר ברירת מחדל עקרונית. הרשאה בפועל יכולה להיות מצומצמת יותר בהתאם לצורך ולסיכון.
