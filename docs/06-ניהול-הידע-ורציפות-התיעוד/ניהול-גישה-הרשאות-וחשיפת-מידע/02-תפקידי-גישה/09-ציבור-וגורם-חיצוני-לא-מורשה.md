# 09 — ציבור וגורם חיצוני לא מורשה

ברירת המחדל היא No Access למידע פנימי של Stock Sentinel.

הציבור נחשף רק לחומר שסווג ואושר במפורש לפרסום.

## Public Release Gate

לפני פרסום בודקים:

- IP;
- מידע רגיש;
- Architecture Reconstructability;
- Security Details;
- נתוני משתמש;
- מידע עסקי חסוי;
- Aggregation Risk מול חומר שכבר פורסם.

## כללים

- Public-by-Approval, not Public-by-Default.
- הארכיון הפנימי אינו Public Documentation Portal.
- אין לפרסם Secrets, Credentials או פרטי גישה.
- מסמך פנימי אינו הופך לציבורי כתוצאה משינוי תיקייה או Share Link בלבד.
- שינוי סיווג דורש אישור מפורש של בעל המוצר.

אם גורם חיצוני זקוק למידע נוסף, עליו לעבור ל־Role המתאים ולהתחיל את תהליך ההרשאה של אותו Role.
