# 05 — מבקר חיצוני

מבקר חיצוני מקבל מספיק מידע כדי לבצע ביקורת מקצועית אמיתית, אך לא יותר מידע מכפי שנדרש לשאלות הביקורת.

## Review Package

לפני ביקורת מוגדרים:

- Scope;
- שאלות הביקורת;
- הראיות הנדרשות;
- רמת החשיפה;
- משך הגישה;
- תנאי הסודיות;
- אופן שלילת הגישה בסיום.

## External Review Exposure-Risk Gate

לפני חשיפה בודקים האם החומר, לבדו או בצירוף חומר שכבר נמסר, עלול לאפשר שחזור, שכפול או appropriation מהותי של המוצר.

יש לבדוק גם Aggregation Risk.

## מדרגות חשיפה מועדפות

Evidence
→ Interfaces / Contracts
→ Validation Results
→ Controlled Excerpts
→ Diagrams
→ Redacted / Synthetic Artifacts
→ Isolated Component View
→ ורק כאשר אין חלופה מספקת, חשיפה עמוקה יותר.

אם ביקורת אינה ניתנת לביצוע בצורה מקצועית בלי להגיע לרמת חשיפה בלתי סבירה, משנים את Scope, מפצלים את הביקורת, מחזקים את תנאי החשיפה או אינם מבצעים אותה במתכונת זו.
