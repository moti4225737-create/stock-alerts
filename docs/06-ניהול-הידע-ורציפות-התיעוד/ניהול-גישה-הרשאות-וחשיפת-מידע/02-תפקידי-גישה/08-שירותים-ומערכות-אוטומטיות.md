# 08 — שירותים ומערכות אוטומטיות

שירותים אוטומטיים פועלים באמצעות Machine Identities ייעודיות והרשאות מינימליות.

## עקרונות

- זהות אחת למטרה מוגדרת ככל שניתן.
- Machine Identity אינה יורשת הרשאות של האדם שיצר אותה.
- אין Self-Escalation.
- Default Deny ו־Least Privilege.
- הרשאה נקבעת לפי הפעולה שהשירות חייב לבצע, לא לפי המערכת שאליה הוא שייך.
- יש להקטין Blast Radius של פגיעה בזהות אחת.

## Secrets

Secrets חיים אינם נכתבים ב:

- Source Code;
- Documentation;
- Archive;
- Git;
- Logs;
- Terminal Output;
- Chat.

כאשר Credential נדרש, הוא מוזרק ממנגנון Secret / Environment מוגן.

תצוגה משתמשת רק ב־Masked Value כגון:

`API_TOKEN = ********`

כאשר קיימת חלופה בטוחה של Short-Lived Credential, Workload Identity או OIDC, היא מועדפת על מפתח קבוע.
