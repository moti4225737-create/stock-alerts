# 07 — רוכש פוטנציאלי

הרשאת רוכש פוטנציאלי נגזרת מתהליך הרכישה ולא מתואר התפקיד.

## שני מסלולי כניסה

### מכירה יזומה
Preparation
→ Targeting
→ Teaser
→ Buyer Interest.

### פנייה נכנסת
Strategic Capability Becomes Visible
→ Buyer Approaches
→ Buyer Qualification
→ Confidentiality Gate.

שני המסלולים מתכנסים לתהליך:

NDA / Confidentiality
→ Controlled Demo / Management Presentation
→ Economic Interest / IOI כאשר רלוונטי
→ LOI
→ Staged Data Room / Due Diligence
→ Protected Technical DD
→ Definitive Agreement
→ Signing
→ Closing / Transfer.

## כללים

NDA אינו פותח אוטומטית את ה־IP.

LOI אינו פותח אוטומטית את ה־Repository.

לפני Technical DD עמוק מבוצעים:

- Buyer Capability Risk Assessment;
- Aggregation / Reconstructability Risk Assessment.

## הוכחת יכולת

Claim
→ Evidence
→ Demo
→ Interface / Contract
→ Controlled Architecture Excerpt
→ Isolated Component
→ ורק אם הכרחי, Restricted Code Inspection.

כאשר הסיכון גבוה ניתן להשתמש ב־Clean Team, Independent Reviewer או Restricted Review Environment.

## לפני Closing

Default Deny ל:

- Live Secrets;
- Production Control;
- Owner / Admin;
- Write Access;
- Unrestricted Repository Copy;
- Unrestricted Archive Access.

Signing אינו שווה Transfer of Control.

## עסקה שנפסקה

Stop
→ Revoke
→ Close Data Room
→ Remove Temporary Access
→ Inventory Disclosed Material
→ IP Exposure Review
→ Preserve Disclosure Record.

## עיקרון

רוכש יקבל מספיק מידע כדי לקבל ולאמת החלטת רכישה, אך לא יכולת מעשית לשחזר, להפעיל או לשלוט ב־Stock Sentinel לפני שהשלב העסקי, המשפטי והאבטחתי מצדיק זאת.
