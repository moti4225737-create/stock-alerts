# 04 — חשיפה לגורמים חיצוניים

גישה חיצונית מתבצעת באמצעות Disclosure Package ולא באמצעות פתיחת הארכיון כולו.

## עיקרון

Role
+ Need-to-Know
+ Process Stage
+ Purpose
+ Risk
→ Disclosure Scope.

## שלבי חשיפה

חשיפה גדלה רק כאשר התהליך מצדיק זאת.

NDA או מסמך דומה הם Gate משפטי לחשיפה מוגנת, לא Master Key למידע.

## תוקף

גישה חיצונית מקבלת כברירת מחדל:

- מטרה;
- Scope;
- בעל אישור;
- תאריך בחינה או תפוגה;
- מנגנון Revocation;
- Disclosure Record כאשר רלוונטי.
