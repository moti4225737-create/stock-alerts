# 03 — מחזור חיי הרשאה

הרשאה היא תהליך מלא ולא פעולה חד־פעמית.

## מסלול

צורך
→ בקשה
→ אישור
→ הקצאה
→ שימוש
→ בחינה
→ חידוש / שינוי
→ שלילה.

## עקרונות

- Access follows current responsibility.
- שינוי תפקיד מחייב Reevaluation.
- אין Silent Privilege Accumulation.
- הרשאות זמניות נסגרות בסיום הצורך.
- Re-entry לאחר סיום גישה הוא החלטת הרשאה חדשה.
- סיום משימה, תפקיד, ביקורת, התקשרות או משא ומתן מפעיל Revocation מתאים.

Access termination הוא חלק מהתהליך עצמו.
