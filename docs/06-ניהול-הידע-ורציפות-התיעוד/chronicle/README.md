# Chronicle — כרוניקת המוצר

ה־Chronicle שומר את הסיפור העובדתי של התפתחות Stock Sentinel.

הוא אינו מחליף את ה־Current Truth ואינו משכפל אותו.

Current Truth עונה:
"מה נכון עכשיו?"

Chronicle עונה:
"איך ולמה הגענו לכאן?"

## תוכן רשומת Chronicle

רשומה משמעותית כוללת:
- Objective;
- Entry State;
- Material Changes;
- Decisions and Rationale;
- Validation / Results;
- Exit State;
- Follow-ups.

ה־Chronicle נשמר לפי תחנות עבודה וספרינטים באופן המאפשר לעקוב אחר התפתחות המוצר לאורך זמן.
