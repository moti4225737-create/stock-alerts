# Chronicle — ספרינטים

תיקייה זו מכילה רשומת Chronicle לכל ספרינט או שלב רשמי משמעותי.

כל רשומה מתעדת את המעבר מ־Entry State ל־Exit State ואת ההחלטות והראיות שהובילו אליו.

## מבנה בסיסי לרשומה

1. R&D ID, title, status, predecessor and successor
2. Objective
3. Entry State
4. Material Changes
5. Decisions and Rationale
6. Validation and Results
7. Exit State
8. Follow-ups
9. Repository Traceability
10. End-of-Conversation Handoff כאשר קיימת שיחת המשך

יחידות R&D משתמשות במזהה `R&D NNN` ובתבנית filename
`YYYY-MM-DD-rnd-NNN-<short-slug>.md` עבור רשומות עתידיות. כללי הפתיחה,
המספור, ה־Register וה־Handoff נמצאים בבית הסמכותי שלהם:

`../../../03-ניהול-הפיתוח-ההנדסי/ניהול-ספרינטים.md`

בסיום ספרינט אין להסתפק ברשימת קבצים או Commits. הרשומה צריכה להסביר את השינוי ברמה שמאפשרת להבין אותו בעתיד ללא תלות בשיחת העבודה המקורית.
